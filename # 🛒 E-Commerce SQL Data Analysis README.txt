# 🛒 E-Commerce SQL Data Analysis

## 📌 Project Overview

This project was completed as part of Data Analyst Internship Task 4.
The objective was to use SQL to analyze an e-commerce database and extract useful business information.

## 🛠️ Tools Used

- PostgreSQL
- pgAdmin 4
- SQL

## 📂 Dataset

Olist Brazilian E-Commerce Public Dataset.

The database contains multiple tables related to customers, orders, products, sellers, payments and reviews.

## 📊 SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- Views
- Indexes

## 💡 Analysis Performed

The project includes analysis of:

- Delivered orders
- Orders by status
- Customer and order information using JOINs
- Total revenue and average payment
- Customers with delivered orders using a subquery
- Delivered orders using a SQL view
- Query optimization using an index
